# Product

**Mission:** give individuals the intelligence, clarity and tools needed to build, protect and understand their wealth.

WealthOS is a sophisticated private-wealth view made accessible to ordinary investors. It is **not** a trading app, a crypto product or a generic chatbot.

## Principles
Financial correctness before visual sophistication · evidence before recommendations · clarity before complexity · security before convenience · trust before monetisation · human accountability for regulated advice · user control and portability of data.

## Version 1 boundary
Non-custodial research, education, record keeping and decision support. No personalised buy/sell instructions, no automatic rebalancing, no discretionary management, no execution, no custody, no return guarantees, no automated or copy trading. Enforced in code by `src/server/compliance/features.ts`; see COMPLIANCE_MATRIX.md.

## Founder demo
A separate **DEMO organisation** ("Founder demo portfolio", `organizations.is_demo = true`) created by `src/server/demo/service.ts`, from the founder's hypothetical balanced mix: ₦10m, 3–5 years, 25% Nigerian money-market funds, 20% Nigerian T-bills, 10% USD short-term fixed income, 30% global equity ETFs, 15% Nigerian equities. The mix is stored as a user-defined, hypothetical target (`model_portfolios.is_hypothetical`) and is never shown to other users as a recommendation.

Instruments are the founder's research candidates (Coronation MMF, Stanbic IBTC MMF, Nigerian T-bills, VT, CSPX, IB01, GTCO, Zenith Bank, MTN Nigeria, Dangote Cement). **Their identifiers and attributes are unverified, and every price and FX rate in the demo is synthetic SAMPLE data** generated by a seeded random walk. The demo banner, badges and data-quality panel say so on every screen. All demo transactions are posted through the real ledger service, so the demo exercises production code paths.
