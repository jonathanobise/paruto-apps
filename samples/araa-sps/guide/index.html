Guide de déploiement

Comment diffuser le kit sur le web, sur WhatsApp et sur les radios communautaires, et comment le mettre à jour.

1. Ce que contient le kit

ÉlémentFormatUsage

2. Sur le web

  • Hébergement. Les vidéos interactives sont des pages statiques : copiez le dossier sur les plateformes existantes de l’ARAA ou sur n’importe quel hébergement web, sans base de données ni serveur applicatif.
  • Intégration. Insérez une vidéo dans une page avec une iframe ; le paramètre lang choisit la langue (fr, en, pt, puis les langues locales).
<iframe src="https://media.paruto.com/araa-sps/videos/ecowas/?embed&lang=fr" width="100%"
  style="aspect-ratio:16/10.6;border:0" allow="autoplay; fullscreen"
  title="Le voyage de Moussa"></iframe>
  • Plateformes de formation. Ajoutez la vidéo comme ressource « URL » ou dans un bloc iframe (Moodle, Chamilo, sites institutionnels).
  • Hors ligne. Copiez le dossier sur une clé USB ou un ordinateur de formation et ouvrez index.html dans un navigateur : tout fonctionne sans connexion.
  • Accessibilité. Sous-titres activables, narration complète pour les personnes qui ne lisent pas, commandes au clavier (barre d’espace : lecture/pause).

3. Sur WhatsApp

  • Quel fichier. Le format 16:9 pour les groupes et les discussions ; le format 9:16 pour le Statut. Les fichiers pèsent environ 4 Mo et se partagent même avec une connexion lente.
  • Relais. Diffuser par les réseaux qui touchent déjà les acteurs : services vétérinaires, associations d’éleveurs et de commerçants, coopératives, interprofessions bétail-viande, canaux de communication de l’ARAA et du PACBAO-2.
  • Message d’accompagnement. Envoyer la vidéo avec un court message, puis le quiz en message séparé pour lancer la discussion dans le groupe :
🐄 Le voyage de Moussa : les règles sanitaires du commerce du bétail. Regardez la vidéo (2 min), puis répondez au quiz ci-dessous. Version interactive : https://media.paruto.com/araa-sps/videos/ecowas/?lang=fr
Quiz : qui délivre le certificat zoosanitaire ? A. Le commerçant B. Un vétérinaire officiel C. Le chef du marché Répondez A, B ou C 👇

4. Sur les radios communautaires

  • Fichiers. Utiliser le WAV (−23 LUFS, prêt à diffuser, niveau homogène d’un épisode à l’autre). L’épisode complet est fourni en FLAC, le même son sans perte dans un fichier plus léger : la plupart des logiciels de diffusion le lisent, et tout éditeur audio l’enregistre en WAV. La fiche de diffusion donne la durée et les repères de début et de fin de chaque capsule.
  • Programmation proposée. Chaque épisode trois fois par semaine pendant quatre semaines, de préférence la veille et le matin des jours de marché à bétail, dans la langue de la zone.
  • Animation. Après la capsule, l’animateur peut reprendre les trois messages clés et ouvrir l’antenne aux questions des auditeurs, avec un agent des services vétérinaires si possible.
  • Preuve de diffusion. Chaque radio renvoie la fiche de diffusion signée (dates et heures de passage).

5. Mettre à jour ou ajouter une langue

  1. Textes. Tous les mots d’une vidéo sont dans videos/<module>/script.js (une clé par langue) ; ceux des capsules dans audio/capsules.js.
  2. Voix. Une réplique = un fichier : videos/<module>/vo/<langue>/<réplique>.mp3. Les voix finales (voix de synthèse haute fidélité là où elles existent pour la langue, enregistrements studio pour le bambara, le peul et toute langue où l’ARAA choisit des voix humaines) remplacent les voix de travail sous le même nom (voir le kit d’enregistrement).
  3. Rendus. node tools/render.mjs <module> refait les MP4 16:9 et les SRT ; ajouter --vertical pour le 9:16. python tools/capsules.py refait les capsules ; node tools/storyboard.mjs <module> les storyboards ; node tools/kit.mjs la page du kit et l’archive des sources.
  4. Prérequis. Node.js 20 ou plus, Chromium (Playwright), ffmpeg, et Python avec Piper pour les voix de travail.

6. Suivi

  • Web : statistiques de l’hébergeur (pages vues, langues).
  • Radio : fiches de diffusion signées.
  • WhatsApp : nombre de groupes et de relais touchés, réponses au quiz dans les groupes.
  • Sur demande de l’ARAA, les réponses aux quiz interactifs peuvent être collectées (formulaire ou standard xAPI/SCORM).

2. On the web

  • Hosting. The interactive videos are static pages: copy the folder to ARAA’s existing platforms or any web host, with no database or application server.
  • Embedding. Put a video in a page with an iframe; the lang parameter picks the language (fr, en, pt, then the local languages).
<iframe src="https://media.paruto.com/araa-sps/videos/ecowas/?embed&lang=en" width="100%"
  style="aspect-ratio:16/10.6;border:0" allow="autoplay; fullscreen"
  title="Moussa’s Journey"></iframe>
  • Training platforms. Add the video as a “URL” resource or in an iframe block (Moodle, Chamilo, institutional sites).
  • Offline. Copy the folder to a USB stick or a training laptop and open index.html in a browser: everything works without a connection.
  • Accessibility. Captions on demand, full narration for people who don’t read, keyboard control (space bar: play/pause).

3. On WhatsApp

  • Which file. 16:9 for groups and chats; 9:16 for Status. Files are about 4 MB and share even on a slow connection.
  • Relays. Distribute through networks that already reach the actors: veterinary services, herder and trader associations, cooperatives, livestock-meat inter-professions, ARAA’s and PACBAO-2’s communication channels.
  • Accompanying message. Send the video with a short message, then the quiz as a separate message to start the discussion in the group:
🐄 Moussa’s Journey: the animal health rules of the livestock trade. Watch the video (2 min), then answer the quiz below. Interactive version: https://media.paruto.com/araa-sps/videos/ecowas/?lang=en
Quiz: who issues the animal health certificate? A. The trader B. An official veterinarian C. The market chief Reply A, B or C 👇

4. On community radio

  • Files. Use the WAV (−23 LUFS, broadcast-ready, consistent level across episodes). The full-length episode comes as FLAC, the same lossless audio in a smaller file: most playout software reads it, and any audio editor saves it as WAV. The cue sheet gives each capsule’s length and in/out cues.
  • Suggested schedule. Each episode three times a week for four weeks, ideally the evening before and the morning of livestock market days, in the language of the area.
  • Presenting. After the capsule, the presenter can repeat the three key messages and open the phone lines, with a veterinary officer if possible.
  • Proof of broadcast. Each station returns the signed cue sheet (dates and times aired).

5. Updating or adding a language

  1. Text. Every word of a video is in videos/<module>/script.js (one key per language); the capsules’ words are in audio/capsules.js.
  2. Voices. One line = one file: videos/<module>/vo/<language>/<line>.mp3. The final voices (high-fidelity AI voices where they exist for the language, studio recordings for Bambara, Fulani and any language where ARAA chooses human voices) replace the scratch voices under the same names (see the recording kit).
  3. Renders. node tools/render.mjs <module> rebuilds the 16:9 MP4s and SRTs; add --vertical for 9:16. python tools/capsules.py rebuilds the capsules; node tools/storyboard.mjs <module> the storyboards; node tools/kit.mjs the kit page and the sources archive.
  4. Requirements. Node.js 20 or later, Chromium (Playwright), ffmpeg, and Python with Piper for the scratch voices.

6. Monitoring

  • Web: the host’s statistics (page views, languages).
  • Radio: signed cue sheets.
  • WhatsApp: number of groups and relays reached, quiz replies in the groups.
  • If ARAA wishes, answers to the interactive quizzes can be collected (a form, or the xAPI/SCORM standard).
