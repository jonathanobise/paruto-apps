Moussa’s Journey · Le voyage de Moussa

A pilot showing our approach for ARAA’s SPS awareness kit (AMI028-2026): one animated story, branching choices with consequences, a built-in quiz, and the same master versioned into French, English and Portuguese, with a light linear cut for WhatsApp.

·

What this sample shows

  • 2D motion design built language-neutral: only the voice and captions change between versions
  • Two branching choices with on-screen consequences, then a three-question quiz with score
  • Runs in any browser and on phones, with no app to install
