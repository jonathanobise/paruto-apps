Set it as your wallpaper

  1. Tap Save Image in the share sheet, so it goes to Photos.
  2. Open Photos, choose the picture, tap Share and then Use as Wallpaper.
  3. Turn off Depth Effect if it hides the clock, then tap Add.
  4. Choose Set as Wallpaper Pair, or Customise Home Screen to use it there only.
