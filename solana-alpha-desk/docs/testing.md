# Testing

```bash
pnpm ci      # typecheck + lint + format check + every Vitest suite
pnpm e2e     # dashboard build + Playwright against the local server
```

| Suite             | Location                  | What it proves                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Unit              | `packages/*/test`         | state machine and handoff contract; money/encoding; strategy thresholds and versioning; Scout bounds (inclusive age and market cap, no FDV substitution, relevant pool, dedup); pool decoders on **real mainnet account bytes**; LP model; every Filter rule F001–F018 incl. "missing never passes"; holder classification and clustering; developer and bundle analysis; factor normalisation, threshold at 70, bounds, reproducibility, ranking; sizing caps; stops (initial, activation, never lowered, trigger); breakers and reset rules; authorization binding; fill simulator (latency, re-quote, slippage, no route, impact, fees); ledger balance and reconciliation; audit checksums; metrics |
| Integration       | `tests/integration`       | full lifecycle discovery → filter → analyst → risk → fill → trailing stop → exit → reconciliation → report → audit verification, on node:sqlite **and on a real D1 binding** (workerd)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Failure injection | `tests/failure-injection` | DexScreener outage, RPC outage, missing indexer, Jupiter outage, duplicate delivery, redelivered transition, concurrent entry race, delayed message after expiry, forged authorization, price move after authorization, DB write failure mid-commit + recovery, liquidity collapse, rugged pool / failed sell + retry, crash during an exit, all-or-nothing fills, daily-loss breaker surviving restart, lease redelivery, dead-lettering, history immutability, one position per token, retention                                                                                                                                                                                                      |
| Replay            | `tests/replay`            | research-mode entries and exits, no look-ahead, timestamp-consistent assessments, no invented scores, period splits and walk-forward                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Security          | `tests/security`          | no signing/broadcast/key code anywhere; no live mode                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| API               | `apps/api/test`           | setup token, session cookie flags, rate limiting, CSRF + origin, MFA enrolment and enforcement, logout, bridge signature/skew/replay/tamper, constraint reporting, every dashboard endpoint, breaker reset phrase                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| End-to-end        | `tests/end-to-end`        | first-run setup in a real browser, every page, mode change, emergency pause and reset procedure, report generation, audit log, mobile layout without horizontal scroll, unauthenticated API refusal                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

Synthetic market data exists **only** under `tests/fixtures` and is labelled as such
(`world.ts`, `fake-market.ts`, `security-evidence.ts`). `mainnet-pools.json` holds real account bytes
captured from mainnet for decoder tests.

Live checks run during development (not part of CI, they hit real APIs): `pnpm discover:once`,
`pnpm replay`.
